# cpp---postage-cost-calculater
A simple C++ program that calculates the shipping cost based on the destination of the package
# Features
- Enter the package weight
- Calculate the shipping cost based on the package weight
- calculate shipping costs for:
   - Deliveries within the city
   - Deliveries outside the city
   - International deliveries
- Calculate the insurance cost
- Display the final shipping cost
  # Technologies
  C++
  # How to Run
  1. Clone the repository.
  2. Open the  source code in a C++ IDE or compiler.
  3. Compile and run the program.
  4. Enter the package weight and required information.
  5. The program calculates and displays the final cost.
  # Purpose
  This project was created to practice C++ programming, User input, loops, conditional statements, and basic calculations
